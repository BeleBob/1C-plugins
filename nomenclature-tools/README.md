# Быстрое переименование номенклатуры

Расширение для 1С:Бухгалтерия предприятия 3.0, платформа 8.3.24+ (писалось под БП 3.0.194, платформа 8.3.27).

| Клавиши | Что делает |
|---|---|
| `Ctrl+R` | выделенные позиции номенклатуры получают **Наименование** и **Полное наименование** из буфера обмена |
| `Ctrl+Z` | откат последнего переименования — после вопроса «Откатить…?» (хранится до 20 операций, можно повторять) |

- Окна не открываются: результат показывается всплывающим оповещением в углу экрана.
- Работает в списке (Справочники → Номенклатура) и в окне выбора номенклатуры (например, из отчета).
- Клавиши работают и из поля поиска: берутся строки, выделенные в списке.
- Команды также есть в меню **Еще**.
- Доступно только пользователю `Стажер` (настройка `РазрешенныйПользователь()` в `МП_ПереименованиеВызовСервера`).
- Что расширение может и чего не может — в [БЕЗОПАСНОСТЬ.md](БЕЗОПАСНОСТЬ.md).

## Как пользоваться

1. Скопировать новое название (`Ctrl+C`). Через AnyDesk буфер синхронизируется — копировать можно и на своем ПК.
2. В списке номенклатуры выделить строки (`Ctrl`+клик или `Shift`+стрелки).
3. `Ctrl+R`. Ошиблись — `Ctrl+Z` → «Да».

Ничего не изменится, если: в буфере несколько строк или таблица; текст длиннее допустимого; хоть одна позиция
не записалась (все пишутся одной транзакцией). Группы пропускаются.
Откат возвращает каждое поле, только если в нем все еще текст из переименования: ручную правку не затирает.

Хоткеи — `Ctrl+буква` без `Shift`: через AnyDesk в обычном режиме сочетания с `Shift` искажаются.

# Установка

Устанавливает **администратор** (в Конфигураторе), пользуется **Стажер**.

1. **Резервная копия базы.**
2. Конфигуратор под администратором → **Конфигурация → Открыть конфигурацию**.
3. **Конфигурация → Расширения конфигурации → Добавить**: имя — любое, префикс `МП_`, назначение «Дополнение»,
   **Безопасный режим — включен**. Выделить расширение → **Конфигурация → Открыть конфигурацию**.
4. В дереве **основной** конфигурации: Справочники → Номенклатура → Формы → правой кнопкой по
   `ФормаСписка` и `ФормаВыбора` → **Добавить в расширение**.
5. В дереве **расширения**: Общие → Общие модули → **Добавить**, вставить код целиком:

   | Модуль | Флажки | Код |
   |---|---|---|
   | `МП_ПереименованиеВызовСервера` | Сервер, Вызов сервера | [src/CommonModules/МП_ПереименованиеВызовСервера.bsl](src/CommonModules/МП_ПереименованиеВызовСервера.bsl) |
   | `МП_ПереименованиеКлиент` | Клиент (Сервер — снять) | [src/CommonModules/МП_ПереименованиеКлиент.bsl](src/CommonModules/МП_ПереименованиеКлиент.bsl) |

6. Для `ФормаСписка` и `ФормаВыбора` в дереве расширения: открыть форму → выделить «Форма (расширение)» →
   свойства → События → **ПриСозданииНаСервере** → 🔍 → **«Вызывать после»** → ОК → вкладка **Модуль** →
   `Ctrl+A` → вставить [src/Forms/МодульФормыНоменклатуры.bsl](src/Forms/МодульФормыНоменклатуры.bsl).
7. Дерево расширения → **Действия → Конфигурация**: **Проверка модулей** → **Проверка возможности применения**
   → **Обновить конфигурацию базы данных**. Перезапустить 1С.

Проверка: под Стажером в списке номенклатуры **Еще** → команды «Переименовать в текст из буфера обмена»
(`Ctrl+R`) и «Откатить последнее переименование» (`Ctrl+Z`). Тест — на двух тестовых позициях.

## Если не работает

| Что видно | Причина и что делать |
|---|---|
| Команд нет в меню «Еще» | Не совпало имя пользователя в `РазрешенныйПользователь()`, или не подключен обработчик из шага 6. Ошибки пишутся в журнал регистрации, событие `МП_МассовоеПереименование`. |
| Хоткей не срабатывает через AnyDesk, а команда в «Еще» работает | Переключить клавиатуру AnyDesk в режим 1:1. |
| «Недостаточно прав» при `Ctrl+R`, хотя вручную переименовать позицию получается | Снять флажок **Безопасный режим** у расширения и обновить конфигурацию БД. |
| «Не выделено ни одной позиции» | В списке ничего не выделено или открыт не список номенклатуры. |

## Как удалить

**Администрирование → Печатные формы, отчеты и обработки → Расширения** (или Конфигуратор →
Расширения конфигурации) → снять «Активно» или удалить. После перезапуска 1С всё как до установки.
Уже сделанные переименования останутся — при необходимости откатить их `Ctrl+Z` до удаления.
