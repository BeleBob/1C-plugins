# 1C-plugins

Доработки для 1С:Бухгалтерия предприятия 3.0.

|---|---|
| [nomenclature-tools](nomenclature-tools/) | Расширение «Инструменты номенклатуры»: массовое переименование из буфера обмена (`Ctrl+Shift+R`, откат `Ctrl+Shift+Z`), объединение выделенных (`Ctrl+Shift+Q`), поиск двойников у товаров с минусовым остатком |
