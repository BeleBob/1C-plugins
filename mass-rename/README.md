# Массовое переименование номенклатуры

Расширение для 1С:Бухгалтерия предприятия 3.0 (платформа 8.3.24+).

| Клавиши | Что делает |
|---|---|
| `Shift+R` | все выделенные позиции номенклатуры получают **Наименование** и **Полное наименование** из буфера обмена |
| `Shift+Z` | откат последнего переименования (можно нажимать несколько раз — хранится до 20 операций) |

Окна не открываются: результат показывается всплывающим оповещением в углу экрана.
Клавиши срабатывают, **только когда курсор стоит в таблице списка**: `Shift+R`/`Shift+Z` — это еще и заглавные
R/К и Z/Я, и набор текста в поле поиска не должен ничего переименовывать.
Побочный эффект: в самой таблице быстрый поиск набором с заглавных К и Я не работает — используйте поле поиска (`Ctrl+F`).
Команды также есть в меню **Еще** списка номенклатуры.

Работает в списке номенклатуры (Справочники → Номенклатура) и в окне выбора номенклатуры
(например, при выборе из отчета).

## Как пользоваться

1. Скопировать новое название в буфер обмена (`Ctrl+C`). Через AnyDesk буфер синхронизируется,
   копировать можно и на своем ПК.
2. В списке номенклатуры выделить нужные строки (`Ctrl`+клик или `Shift`+стрелки).
3. Нажать `Shift+R`.
4. Ошиблись — `Shift+Z`.

Защита от ошибок:
- в буфере должна быть **одна** строка текста; если скопирована таблица или несколько строк — ничего не меняется;
- текст длиннее допустимой длины наименования — ничего не меняется;
- группы не переименовываются;
- все позиции записываются одной транзакцией: если одна не записалась, не меняется ни одна;
- откат не трогает позицию, если ее после переименования уже кто-то изменил вручную.

## Кому доступно

Настраивается в области `Настройки` в начале модулей:

- `МП_ПереименованиеВызовСервера` → `РазрешенныйПользователь()` — пользователь 1С (сейчас `"Стажер"`);
- `МП_ПереименованиеКлиент` → `РазрешенныйКомпьютер()` — имя рабочего ПК. Чтобы узнать: на рабочем ПК
  `Win+R` → `cmd` → `hostname`. Пусто — любой компьютер.

У остальных пользователей команды не появляются, всё работает как раньше.

## Установка (один раз, нужны права администратора)

Устанавливать под **администратором**, пользоваться — под **Стажером**:
- в Конфигуратор входить под админским логином; все шаги ниже — под ним;
- работать с номенклатурой — как обычно под «Стажером»; давать ему права администратора не нужно;
- переименование выполняется с правами «Стажера»: если он может вручную поменять название
  позиции, хоткей тоже сработает;
- под админом команд не будет — они показываются только пользователю из настроек.

Перед установкой в рабочую базу лучше проверить на копии.

### 1. Создать расширение

1. Запустить 1С, выбрать базу, нажать **Конфигуратор**, войти под **администратором**.
   Если такой кнопки нет — установлен только тонкий клиент; нужен дистрибутив платформы 8.3.27
   с компонентом «1С:Предприятие» (полная версия).
2. **Конфигурация → Открыть конфигурацию**.
3. **Конфигурация → Расширения конфигурации → Добавить**:
   - Имя: `МассовоеПереименование`
   - Синоним: `Массовое переименование номенклатуры`
   - Префикс: `МП_`
   - Назначение: `Дополнение`
4. Флажок **Безопасный режим** в свойствах расширения — **оставить включенным** (см. [БЕЗОПАСНОСТЬ.md](БЕЗОПАСНОСТЬ.md)).
5. В списке расширений выделить его → **Действия → Открыть конфигурацию**.

### 2. Заимствовать формы номенклатуры

В дереве **основной** конфигурации: **Справочники → Номенклатура → Формы**.
Правой кнопкой по каждой форме → **Добавить в расширение** → `МассовоеПереименование`:
- `ФормаСписка`
- `ФормаВыбора`

### 3. Добавить общие модули

В дереве **расширения**: **Общие → Общие модули → Добавить** (правая кнопка).

| Имя модуля | Флажки в свойствах | Код |
|---|---|---|
| `МП_ПереименованиеВызовСервера` | Сервер, Вызов сервера (Клиент — снять) | [src/CommonModules/МП_ПереименованиеВызовСервера.bsl](src/CommonModules/МП_ПереименованиеВызовСервера.bsl) |
| `МП_ПереименованиеКлиент` | Клиент (управляемое приложение) (Сервер — снять) | [src/CommonModules/МП_ПереименованиеКлиент.bsl](src/CommonModules/МП_ПереименованиеКлиент.bsl) |

Код вставить целиком в модуль, заменив пустой текст.
Поправить настройки (см. «Кому доступно»).

### 4. Модули форм

В дереве **расширения**: **Справочники → Номенклатура → Формы → ФормаСписка** → вкладка **Модуль**.
Вставить [src/Forms/МодульФормыНоменклатуры.bsl](src/Forms/МодульФормыНоменклатуры.bsl).
То же самое для `ФормаВыбора`.

### 5. Применить

1. В окне расширения: **Конфигурация → Проверка конфигурации** (или `Ctrl+F7` в модулях) — ошибок быть не должно.
2. **Конфигурация → Обновить конфигурацию базы данных** (`F7`). Монопольный режим для расширений не нужен.
3. Закрыть Конфигуратор, запустить 1С:Предприятие под **Стажером** и проверить.

### 6. Сохранить исходники в git

В окне расширения: **Конфигурация → Выгрузить конфигурацию в файлы** → папка `mass-rename/xml` этого репозитория,
затем закоммитить. Так в репозитории будет полная копия расширения (с заимствованными формами).

## Если не работает

- **Команд нет в меню «Еще»** — не совпало имя пользователя в настройках, или форма, из которой
  выбираете, не `ФормаСписка`/`ФормаВыбора`.
- **Клавиши ничего не делают** — курсор не в таблице; кликнуть по строке списка и повторить.
- **Ошибка компиляции про `СредстваБуфераОбмена`** — у конфигурации режим совместимости ниже 8.3.24;
  сообщить, сделаю вариант без него.
- **Ошибка «Недостаточно прав»** при переименовании — у «Стажера» нет права изменять номенклатуру;
  выдать ему это право (не админские права) под администратором.
